ADM02 LAB EXPERIMENTS 1 TO 4 - PYTHON CODE

Files:
1. experiment1_data_collection.py
2. experiment2_relational_nosql.py
3. experiment3_eda.py
4. experiment4_cleaning_sampling.py

Requirements:
    pip install pandas numpy matplotlib scikit-learn openpyxl

How to run:
1. Install Python 3.
2. Open Terminal / Command Prompt in this folder.
3. Install the required libraries using the command above.
4. Run each experiment separately:
       python experiment1_data_collection.py
       python experiment2_relational_nosql.py
       python experiment3_eda.py
       python experiment4_cleaning_sampling.py

Notes:
- Experiment 1 creates a data folder containing the source files and integrated CSV,
  JSON and Excel files.
- Experiment 2 creates hospital.db and patients_nosql.json.
- Experiment 3 displays four graphs and saves exp03_eda.png.
- Experiment 4 creates cleaned_customer_data.csv, train_data.csv,
  validation_data.csv and test_data.csv.

The programs use sample data generated in the lab document. Replace the sample
data with your own dataset if your instructor requires real-world data.
